Skyline Runner — an original alpine flight game: chase-view flying over a valley, ring courses, runway landings, fuel and hull damage.
## Run it
```sh
node main.ts
```
## Play it
Serve `game/` with any static server and open `index.html` in desktop Chrome — no build step, no network requests.
Pick a sortie: **Ring Run** (thread 8 glowing rings, then land on RWY 27), **Runway Landing** (a clean circuit and a gentle touchdown), or **Free Flight**. Controls: W/S throttle, arrow keys pitch & roll, mouse steers while held, B brakes, P pause, M mute. Fuel burns with throttle — green rings refuel. Hard impacts bend the airframe; a smooth landing on the numbers scores.
